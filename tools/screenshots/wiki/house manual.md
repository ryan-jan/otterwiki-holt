# House Manual

## Boiler

The boiler is a combi in the kitchen cupboard. If the pressure drops below 1 bar, top it up with the filling loop underneath.

> [!WARNING]
> Turn the boiler off at the switch before touching the filling loop.

## Meters

- Electricity: under the stairs
- Gas: outside, by the side gate
- Water: in the pavement, with a small blue cover

## Fuse box

The consumer unit is in the hall cupboard. Each breaker is labelled. The `RCD` trips if anything outside gets wet.

```sh
# Read the smart meter's local API
curl http://meter.local/api/v1/data
```
